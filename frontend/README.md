# داشبورد مدیریت ماموریت‌های فروش

یک داشبورد لوکس و کامل برای مدیریت ماموریت‌های فروش با Next.js و Tailwind CSS

## ویژگی‌ها

✨ **داشبورد اصلی**
- آمار کلی در قالب کارت‌های زیبا
- نمودارهای تعاملی (Pie Chart و Bar Chart)
- نمایش ماموریت‌های اخیر
- طراحی مدرن و Responsive

🎯 **مدیریت ماموریت‌ها**
- لیست کامل ماموریت‌ها با فیلتر پیشرفته
- جستجو بر اساس پرسنل، مرکز، وضعیت
- تایید، ویرایش و حذف ماموریت‌ها
- نمایش جزئیات کامل هر ماموریت

📍 **مدیریت مراکز**
- لیست کامل مراکز
- افزودن، ویرایش و حذف مراکز
- فیلتر بر اساس نوع و مسئول

📊 **گزارش‌ها**
- گزارش خلاصه
- گزارش بر اساس پرسنل
- گزارش بر اساس مرکز
- گزارش بر اساس کد تخفیف
- گزارش جزئیات با فیلتر تاریخ

## راه‌اندازی

### 1. نصب وابستگی‌ها

```bash
npm install
```

### 2. تنظیم متغیرهای محیطی

فایل `.env.local` ایجاد کنید:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

### 3. اجرای پروژه

```bash
# حالت توسعه
npm run dev

# ساخت برای تولید
npm run build

# اجرای نسخه تولید
npm start
```

### 4. دسترسی

پس از راه‌اندازی، به آدرس زیر مراجعه کنید:

```
http://localhost:3000
```

## نکات مهم

1. **بکند باید در حال اجرا باشد** - مطمئن شوید که بکند روی پورت 5000 اجرا می‌شود
2. **CORS** - بکند باید CORS را برای localhost:3000 فعال کرده باشد
3. **API Endpoints** - همه endpointها باید در بکند موجود باشند

## توسعه

برای افزودن ویژگی جدید:

1. کامپوننت جدید را در `app/components/` ایجاد کنید
2. API functions را در `app/lib/api.ts` اضافه کنید
3. صفحه جدید را در `app/` ایجاد کنید
4. Route را به Sidebar اضافه کنید

## مشکلات رایج

### خطای CORS
اگر خطای CORS دریافت کردید، مطمئن شوید که در `backend/src/server.js` این خط وجود دارد:
```javascript
app.use(cors());
```

### خطای API Connection
اگر نمی‌تواند به API متصل شود:
1. بکند را بررسی کنید که روی پورت 5000 اجرا می‌شود
2. متغیر `NEXT_PUBLIC_API_URL` را در `.env.local` بررسی کنید
